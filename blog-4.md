Blog 4 : How OOP pillars help in large TypeScript projects  ??

Object Oriented Programming has four main pillars = Inheritance , Polymorphism , Abstraction, and Encapsulation . These concepts help use manage complex code in large TypeScript project .

Inheritance allows a class to use properties and method of another class .This reduces code duplication and helps reuse existing logic . Polymorphism allows one function or method to behave in different ways depending on the object .This makes the code more flexible and dynamic. 

Abstraction helps us hide complex implementation details and only show  necessary features . This make the code easier to understand and use . Encapsulation means keeping data and methods inside a class and controlling access to them . This helps protect data from unwanted changes.
